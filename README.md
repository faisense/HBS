## Human Behavior Analytics project
Computer vision project linking RTSP cameras with vision models to detect/count/track/analyze human behavior.

### System Capabilities
- handling multiple camera streams
- Simple UI to set AI use cases
- AI use-cases(Restricted Areas, counting(in/out), tracking, Density heatmap etc.)
- dashboard to monitor performance
- database

### Technology stack
- Python
- OpenCV
- Docker & Docker Compose
- Grafana & prometheus
